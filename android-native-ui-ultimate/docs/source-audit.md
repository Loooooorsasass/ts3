## Input Package

The source input was `android-native-ui-1.4.0/android-native-ui/` in this workspace: 52 files across `README.md`, `SKILL.md`, `UPDATE-NOTES.md`, 17 numbered references, and the template README, Compose/Views/resources, tests, and `port_check.sh`. The original folder had no `LICENSE` file. All 52 files were copied byte-for-byte before product changes; the inherited files remain unchanged in this product. `LICENSE` therefore records a redistribution notice and does not invent a license grant.

## Selection Decisions

- **Adopted:** repository-first investigation, modular routing, bounded acceptance, regression-first checks when suitable, root-cause debugging, token/state consistency, explicit verification status, and self-contained skills with local references.
- **Adapted:** web design-system ideas become Android semantic tokens and game-specific hierarchy/state rules; general engineering workflows become short local task procedures.
- **Not adopted:** hard-coded framework migrations, a mandatory global process, unconditional agent/issue-tracker tooling, forced TDD for all work, CSS pixel/ARIA-specific recipes, upstream plugins/CLIs/data catalogs, or a universal Android dependency stack.
- **No substantial upstream code or prose was copied.** Attribution here records research provenance; it does not change the original input's license status.

## Audit Scope and Limits

All five snapshots were cloned and their top-level readmes, skill/packaging structures, and applicable license files were inspected. Because repository shapes differ, “router,” “templates,” “tests,” and “packaging” do not exist in the same form in every source. Superpowers documents both plugin tests and separate LLM eval harnesses; Android Skills primarily publishes modular Android instructions and release/plugin manifests; the UI/UX repo ships a CLI/catalog; Anthropic's repo contains diverse examples with per-skill license exceptions. This is a comparative audit, not a claim that every file in each upstream repository was read or every upstream test was run.
